# MediConnect

## Introduction

Application pour une connexion facile entre Client et Medecin

## 🚀 Installation et Configuration

### 🛠️ Prérequis
- [Flutter](https://flutter.dev/) installé sur votre machine.
- Un émulateur Android/iOS ou un appareil physique connecté.
- [Git](https://git-scm.com/) installé.

### 📥 Cloner le projet


git clone https://github.com/Olajjk/MediConnect.git
cd mediconnect

### Installer les dépendances
    flutter pub get



### Pour exécuter mediconnect :

    cd mediconnect
    flutter run -d android

📄 Ressources & Technologies

- Flutter : Développement des applications.
- Firebase : Stockage et authentification.
- API ChatGPT : Recommandation intelligente.
- OCR : Reconnaissance des ordonnances médicales.
